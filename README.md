# Perilous Moons Splits

RuneLite plugin that tracks split times, order-aware personal bests, and per-split food/potion usage for Moons of Peril trips in Neypotzli.

## Development

```bash
./gradlew run
```

## Build for sideloading

```bash
./gradlew shadowJar
```

Copy `build/libs/perilous-moons-splits-*-all.jar` to `%USERPROFILE%\.runelite\sideloaded-plugins\` and enable Developer Mode in RuneLite.
